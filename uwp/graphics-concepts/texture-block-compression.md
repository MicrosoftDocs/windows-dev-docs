# Texture block compression

Block Compression behavior and format support are defined by Direct3D rather than by the UWP app model. UWP apps that use Direct3D use the same BC1 through BC7 formats and feature-level requirements as other Windows apps.

For the canonical format tables and Direct3D 11 guidance, see [Texture block compression in Direct3D 11](/windows/win32/direct3d11/texture-block-compression-in-direct3d-11). For UWP-specific resource guidance, see [Textures](textures.md).
