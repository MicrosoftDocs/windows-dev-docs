# Rasterization rules

Rasterization behavior is defined by the Direct3D graphics pipeline rather than by the UWP app model. The same rules for triangles, lines, points, multisampling, centroid sampling, and derivative calculations apply when a UWP app renders with Direct3D.

For the canonical Direct3D guidance, see [Rasterization rules (Direct3D 11)](/windows/win32/direct3d11/d3d10-graphics-programming-guide-rasterizer-stage-rules). For UWP-specific pipeline context, see [Rasterizer (RS) stage](rasterizer-stage--rs-.md).
