# Use system-generated values

System-generated vertex, primitive, and instance identifiers are features of the Direct3D input-assembler stage rather than the UWP app model. Their behavior is the same when you use Direct3D from a UWP app.

For the canonical definitions and examples, see [Use system-generated values (Direct3D 11)](/windows/win32/direct3d11/d3d10-graphics-programming-guide-input-assembler-stage-using). For UWP-specific pipeline context, see [Input-assembler (IA) stage](input-assembler-stage--ia-.md).
