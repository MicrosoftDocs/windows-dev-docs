# Tools for Windows app development

Choose tools based on how you prefer to build and maintain your Windows app. You can use these tools together or select only the ones your workflow requires.

| Tool | Use it to |
|------|-----------|
| [Visual Studio](../dev-tools/visual-studio.md) | Create, edit, build, debug, and package Windows apps in a full integrated development environment. |
| [WinApp extension for Visual Studio Code](../develop/ai-assisted/vs-code-tools.md#winapp-vs-code-extension) | Run Windows App Development CLI commands from the Visual Studio Code Command Palette. |
| [Windows App Development CLI](../dev-tools/winapp-cli/index.md) | Configure projects and work with package identity, manifests, certificates, packaging, and publishing from the command line. |
| [WinUI Agent](../develop/ai-assisted/winui-agent-plugin.md) | Give a supported coding assistant reusable skills for WinUI development workflows. |

The WinUI Agent includes a UI testing skill that uses Windows App Development CLI commands to inspect and interact with a running app. For setup and examples, see [AI-assisted testing](../develop/ai-assisted/testing.md).

> [!TIP]
> For guided learning rather than tool reference, see [Windows app development tutorials](../tutorials/index.md).
